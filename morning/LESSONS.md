# 学びのメモ（毎朝の判断で読む）

毎週金曜の振り返りで、Claude が記録の集計（`python -m morning.learn`）から書き足す。
- 1項目1行。根拠の件数と平均を必ず書く（例: 「窓+5%以上の上方修正は寄り天が多い（12件、平均-1.8%）」）
- 件数が10件未満のものは【仮説】と書き、まだ判断の決め手にしない
- 集計で否定されたものは消す。全体で30行以内に保つ

## 確かめられたこと（10件以上）
- 寄り付き後に「外す」と決めた銘柄は、残した銘柄より悪い（11件 平均-1.26% / 8件 平均-0.20%）。外す判断は役に立っている
- 開示が「その他」の銘柄は成績が悪い（45件 平均-1.48% 勝率29%）。材料がはっきりしない開示は買わない
- 配当・自社株買いの開示は成績が良い（配当 11件 平均+1.34% / 自社株買い 26件 平均+0.75%）。ただし買い候補にはまだ1件しか入れていない
- 「避けた」銘柄は下がっていない（16件 平均+0.21%、候補全体は-0.06%）。避ける判断は今のところ効いていない
- 朝の買い候補は候補全体より悪い（21件 平均-0.52% / 497件 平均-0.06%）。選び方の見直しが必要

## 仮説（10件未満。様子を見る）
- 【仮説】確信度60〜69の候補のほうが0〜59より良い（6件 平均+0.73% / 15件 平均-1.02%）
- 【仮説】窓+2〜5%で始まった買い候補は成績が悪い（5件 平均-2.17%）。窓+5%以上は平均+0.39%（8件）で、寄り天とは限らない
- 【仮説】「提携」の開示は買い候補でも悪い（4件 平均-3.17%、買い候補1件 -6.72%）
- 【仮説】上方修正の見出しがはっきりした銘柄は良い（6件 平均+1.36% 勝率67%）。一方「業績予想の修正」全体は買い候補で平均-0.69%（18件）と悪く、中身の見極めが要る
