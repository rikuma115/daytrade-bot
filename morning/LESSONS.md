# 学びのメモ（毎朝の判断で読む）

毎週金曜の振り返りで、Claude が記録の集計（`python -m morning.learn`）から書き足す。
- 1項目1行。根拠の件数と平均を必ず書く（例: 「窓+5%以上の上方修正は寄り天が多い（12件、平均-1.8%）」）
- 件数が10件未満のものは【仮説】と書き、まだ判断の決め手にしない
- 集計で否定されたものは消す。全体で30行以内に保つ

## 確かめられたこと（10件以上）
- 【過去2年・4.6万件】寄り付き前に開示が出た銘柄・前日に動いた銘柄を「始値で買って終値で売る」と、平均はマイナス（-0.31%）。良いニュースでも、寄り付きで買うだけでは勝てない
- 【過去2年】上方修正の寄り付き買いは負けやすい（学習用79件 -1.13% / 確認用116件 -0.67%）。良い材料は寄り付きで織り込まれる
- 【過去2年】前日+10%以上 かつ 今日の窓+5%以上は、その日大きく下がりやすい（学習用336件 -3.95% / 確認用369件 -2.52%）。**買い候補にしない**
- 【過去2年】前日+10%以上の銘柄は、窓に関係なく買いは不利（学習用2524件 -0.95% / 確認用2643件 -1.06%）
- 【過去2年】比較的ましなのは、自社株買い・配当予想の修正で窓+2〜+10%（平均+0.3%前後。ただし確認用ではばらつきが大きい）
- 【過去2年】前日-5〜-10%から窓+2〜+5%で反発して始まった銘柄はやや強い（学習用426件 +0.79% / 確認用451件 +0.16%）

## 仮説（10件未満。様子を見る）
- 【仮説】確信度60〜69の候補のほうが0〜59より良い（6件 平均+0.73% / 15件 平均-1.02%）
- 【仮説】窓+2〜5%で始まった買い候補は成績が悪い（5件 平均-2.17%）。窓+5%以上は平均+0.39%（8件）で、寄り天とは限らない
- 【仮説】「提携」の開示は買い候補でも悪い（4件 平均-3.17%、買い候補1件 -6.72%）
- 【仮説】上方修正の見出しがはっきりした銘柄は良い（6件 平均+1.36% 勝率67%）。一方「業績予想の修正」全体は買い候補で平均-0.69%（18件）と悪く、中身の見極めが要る
